# 🏍️ Motorrad Serviceheft

Eine kostenlose, mobile-freundliche Web-App zur Verwaltung von Wartungsplänen und Serviceeinträgen für mehrere Motorräder.

**👉 [App öffnen](https://ricci73.github.io/motorrad-serviceheft/)**

---

## ✨ Features

- **Mehrere Motorräder** verwalten (Marke, Modell, Baujahr, km-Stand, Kennzeichen)
- **Wartungsplan** mit konfigurierbaren Intervallen (km & Monate)
- **Status-Ampel** — zeigt automatisch was bald fällig oder überfällig ist
- **Serviceheft** — alle Einträge chronologisch mit Datum, km, Kosten, Werkstatt
- **Fotos & Belege** direkt zu Einträgen hochladen
- **PDF-Export** — druckbares Serviceheft pro Motorrad
- **JSON-Backup** — alle Daten exportieren und importieren
- **CSV-Export** — Einträge für Excel / Numbers
- **Offline-fähig** — läuft komplett im Browser, kein Server nötig
- **PWA-ready** — kann als App zum iPhone/Android Homescreen hinzugefügt werden

---

## 📱 Auf dem iPhone installieren

1. **Safari** öffnen und [diese URL](https://ricci73.github.io/motorrad-serviceheft/) aufrufen
2. Teilen-Symbol (⬆️) antippen
3. **„Zum Home-Bildschirm"** wählen
4. Die App öffnet sich fortan im Vollbild — wie eine native App

---

## 🔧 Technologie

- Reines **HTML + CSS + JavaScript** — keine Frameworks, keine Dependencies
- Daten werden lokal im **localStorage** des Browsers gespeichert
- Vollständig **offline-fähig**
- Optimiert für **iPhone, Android und Desktop**

---

## 💾 Datensicherung

Da die Daten im Browser gespeichert sind, empfiehlt sich ein regelmäßiges **JSON-Backup**:

1. App öffnen → **📦 Daten** (oben rechts)
2. **JSON-Backup exportieren**
3. Datei sicher aufbewahren
4. Bei Bedarf über **JSON-Datei importieren** wiederherstellen

---

## 🚀 Lokal verwenden

Einfach die `index.html` herunterladen und im Browser öffnen — kein Server, kein Install nötig.
